# 知不知 · Know-unknown

用一个四象限，记下你知道的、还不明白的，以及等待 AI 理解的事。知识、经历、想法和感受，都可以从这里开始。

**[打开应用](https://zherlock0213.github.io/Know-unknown/)** · 手机与电脑浏览器均可使用，首次加载完成后支持离线记录。

## 四象限

横轴从「我不知道」到「我知道」，纵轴从「AI 不知道」到「AI 知道」。

| | 我不知道 | 我知道 |
|---|---|---|
| AI 知道 | **已知的未知**：主动记下的困惑与相关知识建议 | **共同认知**：模型给出理解建议，由你核对确认 |
| AI 不知道 | **未知的未知**：留白，无需填满 | **我的记录**：随手输入，保存后等待理解 |

**当前版本尚未接入 AI。** 可以完整使用记录、离线、导出与恢复功能；新记录不会被自动标为「AI 已理解」，已知的未知也不会自动获得 AI 解答。

保存、模型的理解建议、你的确认，是三个不同的状态。

## 开始使用

1. 点击右下角「我的记录」，写下一件事，保存到本机。
2. 在左上角打开列表后点击「记一笔」，会默认保存到「已知的未知」；也可以在编辑器中选择「我知道 / 我还不知道」。保存前会显示目标象限。
3. 待理解的记录可用「移到左上 / 移到右下」调整归类，原文保留。
4. 在「数据与隐私」中导出 JSON 备份，也可以从备份恢复或删除记录。恢复会替换当前设备中的全部资料。

导出文件包含坐标说明、每条记录的展示象限、用户归类和录入来源，便于交给 AI 阅读。归类由你决定，不会根据文字内容自动纠正。旧记录无法还原的入口会明确标为未知，详见 [归档格式](docs/archive-format.md)。

## 添加到 iPhone 主屏幕

用 Safari 打开 [知不知](https://zherlock0213.github.io/Know-unknown/)，点击「分享」→「添加到主屏幕」。

从主屏幕图标重新打开，等待「已可离线使用」，之后断网也能记录和查看。首次加载需要联网。

联网后可在「数据与隐私」查看应用版本和数据格式，点击「检查更新」。出现「有新版本」时，保存记录后点击「更新应用」；更新会保留本机已保存记录，不会自动刷新其他窗口的编辑内容。

如果早期主屏幕版本没有更新按钮：先保存并导出备份，再从 iPhone 应用切换器完全关闭「知不知」，同时关闭 Safari 中该应用的页面；联网重新打开。如仍是旧版，等待片刻后再次完全关闭、打开，让已下载的版本接替旧缓存。无需删除主屏幕图标或清除网站数据。

## 你的数据

- 记录保存在当前设备、当前浏览器中；没有账号和自动云同步，也不会自动上传给 AI。
- 没有分析追踪或广告。应用未对本地记录加密，导出的 JSON 也是明文，请妥善保管。
- 清除浏览器数据、隐私浏览或设备空间回收可能造成资料丢失，建议定期导出。
- 换设备时，可以手动导出、传送文件并恢复。电脑、手机和不同浏览器各自保存资料。

## 本地开发

使用 React、TypeScript、Vite 和 IndexedDB，离线资源由 Service Worker 缓存。需要 Node.js 22.12+ 和 npm，推荐 Node 24。

```sh
npm ci
npm run dev
```

验证生产环境的离线功能：

```sh
npm run build
npm run preview -- --port 4173
```

打开 `http://127.0.0.1:4173/`，等待「已可离线使用」。开发模式不缓存应用资源。

```sh
npm test          # 领域模型与存储测试
npm run build    # 类型检查与生产构建
npm run test:e2e # 浏览器验收，需要已安装 Google Chrome
```
